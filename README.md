# DemoQA Playwright BDD Project

A Node.js project setup for testing the DemoQA website (https://demoqa.com/) using Playwright with BDD (Behavior Driven Development) approach and TypeScript.

## Installation

1. Clone or download this project
2. Navigate to the project directory:
   ```bash
   cd s7__auto-testing__e2e
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Install Playwright browsers:
   ```bash
   npx playwright install
   ```

## Available Scripts

### Playwright Tests
- `npm run test` - Run Playwright tests in headless mode
- `npm run test:headed` - Run Playwright tests with browser UI
- `npm run test:ui` - Run Playwright tests with interactive UI
- `npm run test:debug` - Run Playwright tests in debug mode
